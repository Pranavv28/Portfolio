---

## 🚀 Key Highlights & Architecture

- **Vanilla Stack**: Pure HTML5, handcrafted modern CSS3, and ES6+ JavaScript (zero framework bloat).
- **Dynamic Multi-Theme Engine**: 4 live themes (Quantum Emerald, Plasma Violet, Solar Amber, Arctic Cyan) switchable via the header button, bottom-left floating dock, or developer console.
- **Hardware-Accelerated Motion**: GSAP 3, ScrollTrigger, and Lenis smooth scrolling.
- **Interactive Developer Console**: In-browser interactive CLI terminal (`Ctrl + K`).
- **Verified Credentials & Lightbox**: Interactive inspection modal for industry internships (Edunet × IBM, Maincrafts), Red Hat System Administration, and cybersecurity certifications.
- **Responsive & Accessible**: Optimized for all viewports from mobile to ultra-wide displays.
